## Loop seam
Last frame: end card on void. First frame: hook on void with line 1 nearly settled. Cut is void-to-void, no black flash (background never goes to pure black; both are `--void` + ambient). Audio: mix decays to −60 dB by 23.90 and starts with the hook downbeat — a clean, intentional hard-in.

## Internal shotlist review (before build)
- *Is the category clear without reading paragraphs?* Shot 3 says it in four words (One coin. One X Manager.) and every later shot shows the X Manager doing something; the end line restates it.
- *Does it escalate?* Score energy is automated per bar (−6 dB build start → 0 dB at activation). Visually: type only → one card → full wizard → full control room → full feed.
- *Is anything fake?* Every UI string above is copied from tryvoice.fun's DOM or JS bundle. Demo content (mention, draft) is marked as example the same way the product's example control room is. Luna is the verified model. Approval Mode, not autonomous.
- *Risk:* the configuration montage is 1.0 s per step. Mitigation: one persistent caption whose object word rolls (read once, then only one word changes), and one focal UI action per step centred by the camera.
- *Risk:* the reply text is the longest read (≈115 chars). It is on screen 16.95–20.00 (3 s) with no competing caption change.
