# film2 build guide (read with `docs/v2/treatment.md`)

The film is **"Night Windows"** (treatment) cut to **Kanye West "Runaway"** (the client's choice), 87.0 BPM.
The treatment's seconds were written for a 100 BPM score. **This guide and `timeline2.json` supersede every time in the treatment.**
Keep the treatment's images, materials, physics, copy and rules; re-time them into the shot's beat range below.

## 2. Architecture (`film2/`)

**Stage layers, back to front:**

| Layer | Use |
|---|---|
| `C.L.world` canvas | The opaque scene |
| `#ui` | Real product DOM |
| `C.L.mul` canvas | `multiply`: ambient and shadow over the UI. Starts white each frame. |
| `C.L.add` canvas | `screen`: light, glass reflections, halation |
| `C.L.front` canvas | Normal: soft foreground planes |
| Grain and vignette | Handled by `main.js` |

**A shot** is `C.shot('s07-brain', (t) => { …draw…; return { grain: 0.045, vignette: 0.1 }; })`, registered at module top level. Optionally export `async function init()` to build textures and DOM once.

**Light model (mandatory; it is why S12 looks physical):**
1. Draw **albedo** (surface colour and texture) to `C.L.world`.
2. Build an **irradiance** canvas: ambient colour plus light sources, using `C.falloff(g, x, y, r0, colour, I)`, an inverse-square radial with composite `lighter`. Half resolution is fine.
3. `multiply` the irradiance onto the world. Texture then shows only where light falls.
4. Draw **emissive** things after the multiply: lamps, lit windows, light-type, the filament.
5. UI sits in `#ui`; put light and shade over it on `mul` / `add`.

**Camera:** `C.cam(x, y, zoom, roll)`, `C.apply(g, cam, z)` (plane depth z > 1 = farther, so less parallax), `C.toScreen`, `C.domTransform`, `C.place(el, cam, wx, wy, z, extraCss, opacity)`. **2D affine only**: no `preserve-3d`, no `perspective`, no `translate3d`.

**Helpers:**

| From | Exports |
|---|---|
| `core.js` | `textSprite`, `canvas`, `ctx2`, `rgba`, `mixHex`, `blurred` (load-time only), `bulb(t, [[t, level]…])` (incandescent on/off curve), `breath(t)` (every manager light after the wake), `fragment(name)` |
| `materials.js` | `concrete`, `plaster`, `asphalt`, `pavement`, `glassWear`, `paperSlip`, `dymo(text, {tape:'black'\|'volt', capH})`, `roadPaint`, `fingerprint`, `valueNoise`, `fbm` |
| `sets/facade.js` | `BAY`, `WIN`, `GROUND`, `PLINTH`, `FLOORS`, `winX`, `winRect`, `drawBlockAlbedo`, `groundModel`, `drawGround`, `drawWindow`, `drawGlass`, `roundRect`, `slatFace` |

These three files are owned by the lead. **Do not edit them.** Put helpers in your own file, and report needed changes in your summary.

**Real UI:** `const el = await C.fragment('model-grid')` (from `init`).
- Fragments: `agent-stats`, `approval-queue`, `brand`, `command-deck`, `decisions`, `launch-heading`, `launch-preview`, `launch-progress`, `launch-step-heading`, `limits`, `memory-accounts`, `model-grid`, `modes`, `permissions`, `teach-feedback`, `treasury-fund`, `treasury-stats`, `voice-group-1`, `voice-is-yours`, `voice-presets`, `workspace-tabs`, `x-account`.
- The site's stylesheet renders them. Change state only through the real classes, attributes and text.
- **Never write invented UI copy.** Real strings are in `capture/fragments`, `capture/site/tabs/*.html` and `capture/js/*.js`.
- Act I cards get the class `colourless` (a token override, not a filter).
- The UI is authored at world size; use `C.place` to position it.

**Determinism (lint-enforced, `node scripts/lint.mjs`):**
- No `Math.random`, `Date`, `performance.now`, timers, rAF, CSS transitions or animations, `will-change` or `translate3d`.
- Seeded `rng` from `../engine/motion.js` (or `C.rng`) only.
- Every frame redraws everything from `t`; no state carried between seeks. Build textures at init only.
- Canvas `filter: blur()` is expensive. Use it per frame only on small regions or for brief moments; otherwise pre-blur at init with `C.blurred`.

**Performance target:** under 120 ms per frame typical.

## 3. Quality bar (non-negotiable)

- **Treatment rules:** §1 (the bible: nobody seen, every light has a source, nothing floats, type lives on surfaces, volt = life (zero volt before 6.8 s), three depths, creator imperfect / manager precise), §4 palette and grade, §5 typography, §12 anti-AI checklist.
- **Legibility:**
  - Narrative words ≥ 96 px on screen.
  - Hold each sentence long enough to read (≥ 1.2 s fully visible).
  - Camera under 4 px/s while a sentence is read.
  - Focal UI text ≥ 48 px wherever the beat is "about" that UI.
- **Pace:** one story event per piano note (≈ 1.38 s) in Acts I–II. Fill between notes with micro-detail: secondary motion with a cause, light shifts, tape and paper settling, dust in light. Never with new information.
- **Materials over graphics:** matte, textured, lit. Contact shadows everywhere. No flat vector look, no glossy CG, no neon, no glow without a source, no floating cards, no generic gradients, no black-void backgrounds (night = moonlit graphite).
- **The S12 look is the reference:**
  - Graphite / moonlit ambient `#1a2127`.
  - Volt spill with tight falloff.
  - Lamp = the logo tile as a frosted lightbox.
  - Light bands on surfaces.
  - Glass with faint wear.

  Render a still at `t = 17.68` to see it.

## 4. Test loop

```
node scripts/render.mjs --timeline timeline2.json --stills 9.70,10.3,10.9 --stills-dir review/v2/<your-set>
```
- Then **Read the PNGs and look at them critically**, as a commercial director would.
- Console errors print to stderr. `window.__setErrors` holds per-set load errors.
- Iterate until every frame would pass the treatment's poster test.
- Run `node scripts/lint.mjs` before finishing.
